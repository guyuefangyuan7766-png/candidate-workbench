**语境例外：** “已从当前职位解除关联”“当前职位候选人导出”“候选人已创建并关联当前职位”里的“当前职位”指正在查看的招聘职位，不是候选人任职。可保留或改成“该招聘职位”，不得替换为“最近职位”。“关联职位”“招聘职位”“入职职位”“期望职位”也不改为“最近职位”。

保留北森原始表头、外部导入别名、历史活动原文、原始附件内容、服务端查询标识及既有兼容解析规则。字段映射展示名改成新文案，但旧表头仍能识别。不要全仓库无差别字符串替换。

## 4. 全站视觉与交互

- React 19 + TypeScript + Vite 7，沿用 Lucide React 图标。现有 Express/SQLite 服务与契约保留。
- 白色内容区，浅灰侧栏，主蓝 `#3370FF`，主文字 `#1F2329`，次级文字 `#646A73`，分隔线 `#DEE0E3`。语义成功绿色、警告琥珀色、危险红色不统一染蓝。
- 1536×1024 为设计图基准，1440×900 为常见桌面验收尺寸；补查 1280×800、768×1024、390×844。
- 主侧栏约 208px，可收起 72px；分组/会话次栏约 240–260px。主标题约 24px，正文 14px，元信息 12px；控件高 36–40px，圆角 4–6px。
- 表格强调人才姓名、最近职位/公司及关键摘要；表头与分页可达，横向滚动只发生在表格内部。
- 候选人详情始终从右侧打开。充足宽度可并排，但不得把列表压到不可用；普通桌面使用右侧覆盖抽屉。窄屏全屏详情。不按图片强行塞四列。
- 详情页签固定：**档案、履历、历史评估、备注与动态、高级信息**。职位/人才库关系在档案中；附件按现有履历/附件组件组织。
- 新增/编辑复用同一分区表单。固定底部保存/取消；可滚动正文；加载、失败、保存中、空状态均可识别。
- 焦点可见；弹窗有名称、合理初始焦点、关闭后回到触发处；长标题换行，键盘可到达分页与行操作；关闭/切页时不误提交。
