## 二、本轮逐图修正清单

1. 全局抽屉尺寸：主抽屉 520 → 480；表单抽屉 720 → 500（设计图 14/16 实测约 490）。
2. 宽屏（≥1440）抽屉改为与页面并排、取消遮罩（设计图 09/11/13 均为并排可见列表），窄屏仍为覆盖式。
3. 列表（02）：行高对齐 84px、取消行分隔线、头像 40px 圆角方形（单字回退避免换行）、列宽节奏 190/170/130/140/140/150/120、人才库分组与标签改为蓝底 chip、关联/分组的多值改为紧凑 `+N`、更新时间列右置；并排打开抽屉时隐藏标签列，对应设计图 09 的紧凑列集。
4. 抽屉档案（09）：新增「姓名」行、行高 55 → 35、去掉行分隔线与字段图标、标签列宽 120、身份区下方留白 +28、`显示` 按钮 26px 且去图标、卡片标题 16px。
5. 抽屉履历（10）：分组卡（工作经历/教育经历/项目经历/专业技能/其他资料）+ 时间靠右 + 时间线圆点。
6. 抽屉历史评估（11）：来源记录卡（标题+日期+来源+正文）+ 折叠「查看来源字段」。
7. 抽屉备注与动态（12）：时间线类名修正、跟进备注输入卡与动态记录卡分离。
8. 抽屉高级信息（13）：按需加载空态、数据血缘行、来源记录/职位申请来源/授权与隐私记录折叠行。
9. 职位管理（04）：操作列常显（编辑 + 更多菜单），职位名链接 15px 加粗；候选人表仍为悬停显示行内操作。
10. 人才库分组（03）：补成员搜索框（走 `/api/talent-pools/:id/candidates?search=`，与分组搜索分离）。
11. 履历检索（07）：结果表改为「候选人 / 所在城市 / 学历 / 工作经验 / 最近公司 / 匹配证据 / 操作」，行内 56px 头像、`查看档案` 36px 描边按钮，搜索框 48px、`检索` 44px。
12. 术语层：候选人语境统一「最近职位 / 最近公司 / 最近经历与教育摘要」，`current_title`、`current_company` 等字段键、API 键与数据库列保持不变。

## 三、关键功能验收（匿名库，30/30）

- 列表：标题与范围页签、搜索命中与空结果、学历筛选与服务端一致、分页与按职位视图、导出菜单、批量归档确认（可逆）。
- 详情：固定五页签（档案 / 履历 / 历史评估 / 备注与动态 / 高级信息）、敏感资料按需加载、附件区与原文、编辑分区表单。
- 人才库：主从布局与成员分页、新建/编辑、加入/移出、归档与恢复。
- 职位：状态页签与统计、职位详情关联候选人与解除关联、新增职位表单。
- 导入：选择文件、字段映射（旧表头映射到 `current_company` / `current_title`）、预览校验与问题行、重复候选人更新提示、任务恢复。
- 附件解析：入口与真实状态、候选人附件与原文。
- 履历检索：关键词结果与旧请求状态（取消 / 重试 / 条件变更提示 / 降级与完整性提示）。
- 助手：未配置模型网关时不伪造答案。
- 术语：候选人语境旧术语命中为 0。
- 响应式：全部入口 + 五个详情页签在 1440 / 1280 / 768 / 390 均无根节点横向溢出。

## 四、未解决限制

1. **AI 助手（图 06）**：匿名环境未配置模型网关，只验证真实未配置状态，不伪造会话历史列、流式回答与工具调用；设计图中的会话历史列表属于「已配置」状态。
2. **附件解析（图 20）**：差异逐项写入依赖本地解析网关；匿名环境验证批次、候选人文档与无建议降级，未验证模型建议的逐项写入。
3. **虚构内容差异**：设计图使用合成数据（1280 位候选人、238 位成员等），实现按匿名库真实数据渲染，行数、计数与示例文案与图不同。
4. **头像**：匿名库无照片，列表/抽屉使用姓名首字占位（第十一轮起为 52px / 100px 圆角方形，与设计图实测一致）；真实照片仍走 `has_photo` + `/api/candidates/:id/avatar`。
5. **紫色高级色**：按规范只用于品牌区、选中态描边/底纹、空态浅底与图表辅助序列，同屏不超过 3 处，不替代 `#3370FF` 主操作色。
6. **候选人库筛选（图 02）**：设计图筛选 chip 为「学历 / 地点 / 工作年限 / 人才库 / 关联职位 / 更多筛选」，当前 `/api/candidates` 无「地点」「工作年限」查询参数，按约束未改服务端，实现为「学历 / 人才库 / 关联职位 / 来源 / 更多筛选」。

### 实现结论

- `src/workspace.css` 第十二轮段落集中定义 `:root` 尺度 token，并按 1919 / 1599 / 1365 / 1151 / 1023 / 720 的 `max-width` 降序覆盖。主标题为 34 / 32 / 28 / 26 / 24 / 22 / 20px，数据行为 72 / 68 / 62 / 58 / 56 / 54 / 60px。
- 候选人、人才库成员、职位和履历检索四张主表使用 `table-layout: fixed` 与稳定 `tw-col-*` 类名；弱信息按档位显式隐藏，任一验收表均满足 `scrollWidth <= 容器 clientWidth + 2px`。
- 并排详情抽屉按 ≥1600、1440–1599 两级隐藏列，1440–1599 同时隐藏履历检索的`最近公司`；窄档改为全宽/全屏覆盖。
- 主页面、工具页和导入页收敛为 `Surface` 单一联合状态；URL、侧栏高亮和屏幕内容一致，重复点击回到进入前页面，`popstate` 可逆。
- D1–D10 已落实：关键词召回、补齐语义、真实总数、单点布局修复、统一关闭弹层、命名与口径统一、桌面顶栏助手入口。

### 截图与已知偏离

- `screenshots/viewport-<宽>x<高>-<页面>.jpg` 90 张覆盖 15 视口 × 6 页面，另有 3 张 `viewport-<宽>x<高>-candidates-drawer.jpg` 对应抽屉布局断言，共 93 张 JPG；不覆盖 22 张设计图对照图和 `round10-*` 文件。

- 22 张设计图的既有 AI 助手未配置网关、附件差异建议限制仍适用；本轮没有通过真实模型网关补测这两类状态。
