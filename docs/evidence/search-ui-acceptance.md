## 实际修复

- 768px 下侧栏已按 900px 断点收起，但主题仅在 720px 以下显示移动菜单，导致导航不可达。已将菜单可见范围对齐现有 900px 断点。
- 候选人页专用零内边距覆盖移动端顶部预留空间，菜单与第一行操作过近。已在移动导航断点为候选人页预留 48px。
- 检索和附件页返回按钮使用绝对定位，长结果滚动后会覆盖正文，附件页标题也被按钮覆盖。两页 header 改为独立固定高度布局，保留原返回按钮、位置和行为，内容在其下滚动。
- POST 客户端超时改为 48 秒以覆盖服务端 45 秒预算；索引变化错误同步作废旧游标。
